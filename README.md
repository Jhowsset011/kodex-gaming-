# Kodex Gaming

Tienda gaming estática con catálogo, búsqueda, filtros y carrito local.

## Desarrollo

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

No requiere instalación ni compilación. Los precios son de referencia; no procesa pedidos o pagos.

## GitHub Pages

En Settings → Pages, selecciona Deploy from a branch, main y / (root).
